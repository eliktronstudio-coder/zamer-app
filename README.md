# Замер

Поэтапное PWA-приложение цифрового замера. Реализованы фазы 0–11 и автоматизированная QA/Beta фазы 12 (внешний Supabase подключается позже): архитектура, локальные гостевые проекты/этажи, поиск и управление объектами, геометрическое ядро и 2D-редактор на Konva. Можно строить стены с точными длинами, выбирать и перемещать их, редактировать параметры и размеры, отменять/повторять команды, масштабировать и перемещать лист мышью или пальцами. Связи и размеры сохраняются в IndexedDB и доступны offline после загрузки PWA. Колонны всех базовых сечений, окна, двери, проёмы, балки, лестницы, пандусы и перепады уровня доступны в списке «Конструкции». Замкнутые контуры дают площадь сразу; помещения с пользовательскими именами, независимыми статусами и расчётами пола/потолка/стен/проёмов/объёмов сохраняются offline. Доступны итоги этажа и объекта. Подготовлены аккаунты, облачная очередь, RLS и разрешение конфликтов с сохранением копии; настройку настоящего Supabase пользователь отложил. Дефекты с размерами, привязками и отметками на плане, фотографии с отдельными оригиналами/превью и обратимой корзиной работают offline. 3D текущего этажа строится из общей модели; доступны ведомости, смета и отчёты PDF/JPEG/XLSX; полный ZIP и импорт редактируемой копии сохраняют модель, оригиналы фото, цены и историю документов.

## Запуск

Для входа с телефона/другого компьютера подготовлено HTTPS-размещение на Cloudflare Pages: [инструкция](docs/hosting.md), [протокол Beta](docs/beta-acceptance.md). Готовый ZIP сайта — `artifacts/zamer-beta-site.zip`. Внешний адрес ещё не создан: требуется публикация в аккаунте Cloudflare. Гостевые объекты хранятся на устройстве; перенос до подключения Supabase — через полный ZIP проекта.

Node.js >=22.12 (проверяется на Node 24). В корне проекта:

```sh
npm ci --cache /workspace/.npm-cache
npm run dev
```

```sh
npm run check
# В этой cloud-среде уже есть /usr/bin/chromium:
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
# На другой машине при отсутствии Chromium:
npm exec playwright install chromium
npm run build
npm run test:e2e
```

Для production shell и offline используйте `npm run preview -- --port 4173` после build. Dev server не проверяет production service worker. Первый визит требует сеть. Нет обязательной регистрации, API-ключей или демонстрационных объектов. Гость хранит данные только в своём браузере. IndexedDB не заменяет облачный backup. Корзина пока без автоматической очистки.

## Управление планом

«Стена» → начало на холсте → направление мышью или стрелками панели → длина, например `4,257` → Enter. Esc завершает цепочку. «Выбор» позволяет редактировать параметры и перетаскивать уже выбранную стену. «Размер» добавляет справочный размер стены. Колесо/два пальца меняют масштаб; пустой лист или «Рука» позволяют панорамировать. Ctrl/⌘+Z отменяет, Ctrl+Y или Ctrl/⌘+Shift+Z повторяет, Delete удаляет. История ограничена 100 командами и действует до закрытия этажа. При конфликте вкладок доступно восстановление своей копии на отдельном этаже.

В «Конструкциях» выберите тип, задайте параметры и нажмите «Использовать параметры», затем укажите положение на плане. Окна, двери и проёмы ставятся нажатием на стену в центре будущего элемента; балка — двумя точками. Линия/область уровня завершается кнопкой в свойствах. Переключите «Выбор», чтобы переместить, изменить или удалить конструкцию. При сокращении стены невозможный проём сохраняет размеры и отмечается предупреждением.

«Помещение» → нажмите внутри замкнутого контура (либо «Добавить контур» под планом) → задайте своё название/высоту → «Добавить помещение». Высота без ввода берётся с этажа. «Завершить помещение» проверяет данные и позволяет завершить с замечаниями. Геометрическая замкнутость не означает завершение работы. Удаление стены оставляет запись помещения для ремонта; перепривязка контура сохраняет имя и UUID. Методика расчёта доступна под планом.

Панель «Нестыковки» под планом показывает проблемы всех этажей и позволяет фильтровать их. «Показать» открывает этаж, выделяет элемент и центрирует план. Небольшой разрыв или безопасный дубль могут иметь предложение с явным «Да, применить» / «Нет, оставить». Без вашего действия геометрия не меняется; исправление можно отменить.

В «Аккаунт и облако» доступны вход, регистрация и восстановление пароля после настройки публичных переменных. Гостевые объекты подключаются к облаку явно. Статус локального сохранения отделён от подтверждения облака; offline изменения остаются в очереди. Новое устройство загружает объекты кнопкой на странице списка. Конфликт требует выбора и сохраняет вашу локальную копию.

«Дефект» → точка на плане → описание и размеры → «Сохранить дефект». Фото прикрепляется к сохранённому дефекту или отдельно к объекту/этажу/помещению/элементу. «Скачать оригинал» сохраняет исходные байты; корзина фото/дефектов обратима. На новом устройстве оригиналы загружаются явно.

«3D вид» открывает модель текущего этажа: вращение мышью/одним пальцем, масштаб колесом/двумя пальцами, перенос правой кнопкой/двумя пальцами. Доступны общий вид, вид сверху, скрытие заполнений проёмов и PNG-снимок. Выберите элемент на модели или в списке и откройте его свойства в 2D.

«Ведомости и документы» формирует работы из сохранённого плана и дефектов. Исключите ненужные строки из сметы, заполните справочник цен, выберите объект/этаж/помещение и состав документа. «Создать PDF/JPEG» сохраняет файлы в локальную историю; скачивание доступно там. JPEG — отдельный файл на страницу. Цены и история пока хранятся только на устройстве.

После каждой фазы требуется рабочая сборка и проверки. Приложение не готово к публичному запуску до проверки всех критериев ТЗ.

«Экспорт всего проекта» → «Скачать весь проект»: ZIP с отчётами PDF, планами/видами JPEG, оригиналами и `06_Исходные_данные/project.json`. На странице объектов «Импортировать проект» проверяет ZIP до записи и создаёт новый объект с новыми UUID. Отдельный project.json переносит модель и цены, но не файлы/историю; предупреждение показывается до импорта. Нужны все оригиналы на устройстве. ZIP до 256 МБ; XLSX ведомости и смета включены. В «Ведомости и документы» доступна кнопка «Создать XLSX» с сохранением в историю, в том числе offline. Суммы фиксируются на момент экспорта; редактирование в Excel не пересчитывает их и не изменяет проект. Для QA/Beta доступны `npm run test:beta:load` и `npm run test:beta` после build. Метрики и скриншоты сохраняются в artifacts. Реальные устройства, браузеры и внешний backend ещё требуют проверки; статус — в [матрице выпуска](docs/release-readiness.md).
