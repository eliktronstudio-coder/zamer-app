# Этап 14 — внешнее размещение и Beta-приёмка

Пользователь запросил следующий этап и доступ к приложению по сети; выбран Cloudflare Pages с постоянной HTTPS-ссылкой. Это расширение после исходных фаз 0–12. Настоящий Supabase остаётся отложенным: гостевой режим для размещения не требует backend.

Подготовлены правила Cloudflare Pages: SPA маршрут `/projects/*` возвращает index.html, HTML/service worker/manifest обновляются без долгого кеша, assets с hash кешируются отдельно. Добавлены инструкции Direct Upload и официальной CLI, а также протокол приёмки реальных устройств с ожидаемыми результатами и полями фактического статуса.

Production-пакет `artifacts/zamer-beta-site.zip` содержит только файлы dist, index.html находится в корне. Исходники, .env, QA-фото и snapshots не входят. SHA-256/размер/число файлов сохранены в соседнем `zamer-beta-site-info.json`. Архив проверен CRC и сравнением всех файлов со сборкой; HTML ссылки и manifest icons разрешаются в реальные файлы.

На этом этапе прошли production build/typecheck и четыре Chromium desktop/mobile smoke сценария: гостевой объект с offline reload и XLSX с неизменной историей. Wrangler 4.148.0 установлен через npm cache отдельно от приложения; pages deploy help выполняется. Никакие create/deploy/auth операции Cloudflare не выполнялись. Полный набор 329 unit и 91 browser сценарий проходил на предыдущем этапе, не выдаётся за повторный запуск здесь.

Внешний deployment не завершён. Cloudflare endpoints получили 403 от прокси среды; hosting credentials/Account ID отсутствуют. В настройках cloud environment подготовлены дополнительные домены и безопасная привязка CLOUDFLARE_API_TOKEN, переменные Account ID/имя Pages-проекта и инструкции запуска. Применение настроек и внешняя аутентификация ещё нужны. Альтернатива — загрузить готовый ZIP из своего браузера через аккаунт Cloudflare; секреты тогда не нужны в этой среде.

Рабочую HTTPS-ссылку пока не выдаём: её создаст Cloudflare после deploy, затем необходимо проверить адрес. Публикация облачной среды не публикует веб-приложение. [Размещение](hosting.md), [приёмка](beta-acceptance.md), [незакрытые критерии](release-readiness.md).
