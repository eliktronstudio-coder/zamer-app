# Фаза 11: полный ZIP и импорт редактируемого проекта

В плане доступен «Экспорт всего проекта» → «Скачать весь проект». ZIP объединяет актуальный полный отчёт PDF, дефектную ведомость, смету, планы JPEG, виды 3D, оригиналы фото, историю документов и project.json. Сохраняются точные числа, связи, корзина, используемые цены и исключённые работы. Подписи размеров на экспортируемом плане отрисовываются поверх стен с белой подложкой и не перекрываются толщиной линии. При отсутствии оригинала экспорт просит загрузить его; недоступный WebGL отмечается предупреждением.

На странице объектов «Импортировать проект» проверяет архив до записи, показывает состав и создаёт новый объект с новыми UUID. Исходный объект остаётся доступен. Оригиналы совпадают байт в байт, исторические отчёты сохраняют готовые файлы/источники, цены копии не перезаписывают общий справочник. JSON без ZIP поддерживается с явным предупреждением о недоступных файлах и истории. Импорт работает offline после установки PWA и не включает облачное сохранение автоматически.

Добавлены package v1 и Dexie v8 с projectWorkPrices; cloud snapshot/RPC v5, geometry v4 и SQL 0001–0004 не менялись. Миграция v7→v8 проверена на существующих документах и ценах. Подключение настоящего Supabase остаётся отложенным пользователем.

Проверки: 315 unit/storage/SQL тестов в 19 файлах; полный обычный browser набор — 68 desktop/mobile сценариев, 12 cloud случаев пропускаются и исполняются отдельно с Auth/RPC/Storage mocks. Проверяются точные 4,257 м, переназначение ссылок, фото/история/цены, квота с откатом, legacy JSON, пути/CRC/SHA, поддельные размеры deflate, симлинки, offline импорт/редактирование/reload и отказ неполного экспорта. Скачанный PDF проверен pdftotext. Браузер запускается на стабильной сборке: замена dist во время тестов делает прежние lazy chunks недоступными.

Ограничения ZIP и архитектура — [ADR 0011](adr/0011-portable-project.md). XLSX пока не включён. Приложение пока не объявляется готовым к публичному запуску.
