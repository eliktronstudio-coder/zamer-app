# Фаза 8: дефекты и фотографии

Добавлены форма дефекта, точка/область на плане, привязки к этажу/помещению/элементу/поверхности, размеры, площадь/объём, комментарий, рекомендуемые работы и статус. «Показать дефект на плане» центрирует viewport. Отдельные фото можно привязать к объекту, этажу, помещению или элементу; фотографии дефекта наследуют его привязки. Есть мобильный camera input.

Оригинал сохраняется отдельным Blob с точными байтами, SHA-256 и исходным именем. JPEG-превью ограничено 1280 px. Файлы обрабатываются последовательно, до 50 МБ; unsupported MIME/сигнатуры отвергаются. Обратимая корзина фото/дефектов и корзина объекта сохраняют исходники. Скачивание оригинала работает локально. Данные для отчётов доступны из репозитория, формирование документов последует в фазе 10.

Подготовлены PostgreSQL metadata/RLS и private Storage транспорт: cloud ACK принимается после проверки оригиналов, retry не меняет принятую команду. На новом устройстве оригинал загружается явно и проверяется до кеширования. Внешний Supabase пользователь подключит позже; проверка использует локальный PostgreSQL/PGlite и browser mocks.

## Проверки

**255 unit/storage/SQL тестов** в 16 файлах прошли, как и TypeScript/ESLint/production PWA build. Браузер: **46 обычных сценариев** и **12 cloud сценариев** на desktop/mobile. Обычный запуск явно пропускает 12 cloud сценариев, которые запускаются отдельно с Auth/RPC/Storage mocks; это не live Supabase проверка. Проверяются сохранность байтов, превью, offline reload, rollback, binding/CAS, checksum, snapshot/IndexedDB migration, conflict copy, Storage retry и новое устройство. См. [ADR 0008](adr/0008-defects-and-photos.md) и [стратегию тестов](testing.md).

Визуальная проверка 1366×900 и 390×844: отметки дефектов и превью отображаются, нет ошибок JavaScript и горизонтального переполнения. Панель инструментов не перекрывает раздел фото. Скриншоты: `/tmp/zamer-phase8/{desktop,mobile}.png` и `{desktop,mobile}-plan.png`.

## Границы

IndexedDB v6, project.json v5, геометрия v4; старые команды отправки не переписываются. SQL добавляет миграцию 0004. Live Supabase, реальные камеры/HEIC, нагрузка 2000 фото и независимый Storage backup пока не проверены. Физическое удаление оригиналов не включено. Формы сохраняются явно; Undo/Redo геометрии не отменяет операции фото/дефектов. Полный список ограничений — ADR 0008.

Инструкции `start_skill` облачной среды обновлены и сохранены как черновик. Установка, сеть и другие настройки сохранены без изменений; публикация выполняется в настройках среды.
